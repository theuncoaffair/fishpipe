# Bug fixes

- Opening a folder now reports when no file manager is available instead of showing a missing-file error.
- Holding backward in the audio player now keeps audio playing while seeking.
- The tracked-creator menu now shows only Open profile, Analyze, and Delete, with a divider before Delete.
- The photo slideshow viewer now has a TikTok button before the overflow menu.
- Expired short story links now show the story-expired message instead of a generic resolve error.
- Update checks now still run after a crash dialog or a deep-link launch.
- Audio player header buttons now use consistent 48dp touch targets and theme dimensions.
